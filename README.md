# KLEPTO

A roguelite for the browser after Quazatron (Graftgold, 1986). You are KLP-2,
a small droid with a grapple. Latch on to other droids, beat them in a
circuit-board duel and steal their parts: thrusters, lasers, cloaks and more.
Each part changes how you fight and which sealed vaults you can open.

Desktop only, played with a keyboard or a gamepad.

Run it locally with `python3 -m http.server 8080` and open
http://localhost:8080. There is no build step.

Built with [three.js](https://threejs.org). Quazatron was written by Steve
Turner and published by Hewson in 1986; KLEPTO borrows its ideas, not its code
or graphics.
